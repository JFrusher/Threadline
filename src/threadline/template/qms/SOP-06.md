# SOP-06 Post-Market Surveillance

**Purpose.** Collect and act on post-market data (ISO 13485:2016 §8.2.1; UK MDR 2002 Part 4A).

## Procedure
1. Keep a PMS plan (`doc_type: pms_plan`) listing data sources: complaints, field feedback, SOUP anomaly lists,
   vulnerability feeds (`sbom.yml`), literature, usage telemetry where available.
2. Review the data at the interval set in the plan; record trends and decisions.
3. Produce the periodic report required for the device class in Great Britain (PMS report or PSUR) as a document
   (`doc_type: pms_report`).
4. Update hazards, risk controls and the clinical evaluation where the data shows new or changed risk.

## Records
PMS plan, PMS reports, linked hazard updates.
